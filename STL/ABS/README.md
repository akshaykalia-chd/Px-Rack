The STL must be printed using the following parameters at a minimum. Stronger and higher-quality configurations are acceptable.

## 3D Print parameters ##

### Quality ###

1. Material: ABS/ABS+
2. Infill: 20% or above
3. Layer height: 0.2 mm
4. First Layer height: 0.24 mm
5. Precise Wall: True
6. Wall loops: 4


### Strength ###

1. Top Surface pattern: Monotonic Line 
2. Bottom Surface pattern: Monotonic Line
3. Sparse Infill density: 20%
4. Sparse Infill pattern: Gyroid
5. Internal solid Infill pattern: Monotonic
